# Fixed chat-server bench, 2026-11-15

Historical: this bench covers the previous MiniCPM-V server. The live server changed on 2026-11-19; current numbers are in `MODEL.md`.

Three prompts, 300 tokens, temperature 0, seed 7, prompt cache off, two rounds per run. The server is the MiniCPM-V 4.7 35B-A3B IQ3_XS file with the 4x projector and the Q4_K_M draft flags described in `docs/MODEL.md`.

Weighted tok/s is total tokens divided by the sum of (tokens / tok/s). Acceptance is accepted draft tokens over drafted tokens.
